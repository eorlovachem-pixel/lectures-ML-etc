# Серия конспектов: нейронная сеть с нуля

## Назначение

Эта серия собрана для лабораторной работы **«Нейронная сеть с нуля»** и опирается на указанные материалы Stanford CS231n и MIT OpenCourseWare. Конспекты идут от устройства прямого прохода к ручному обратному распространению, численной проверке градиента и диагностике обучения.

## Карта лабораторной работы

```text
EMG-сигнал 16 × 400
        ↓
6 признаков на канал
        ↓
96 признаков на нажатие
        ↓
разбиение по recording / day
        ↓
масштабирование только по train
        ↓
Linear → ReLU → Dropout → Linear
        ↓
stable softmax + cross-entropy
        ↓
ручной backward
        ↓
gradient check
        ↓
эксперименты с learning rate и Dropout
        ↓
честная оценка по трем схемам
```

## Единые обозначения

| Обозначение | Смысл | Форма |
|---|---|---:|
| $N$ | число объектов в batch | скаляр |
| $D$ | число входных признаков | скаляр |
| $H$ | число скрытых нейронов | скаляр |
| $K$ | число классов | скаляр |
| $X$ | входной batch | $N\times D$ |
| $W_1$ | веса первого слоя | $D\times H$ |
| $b_1$ | смещения первого слоя | $H$ |
| $Z_1$ | линейный выход первого слоя | $N\times H$ |
| $H_1$ | активации после ReLU | $N\times H$ |
| $W_2$ | веса выходного слоя | $H\times K$ |
| $b_2$ | смещения выходного слоя | $K$ |
| $S$ | logits / scores | $N\times K$ |
| $P$ | вероятности после softmax | $N\times K$ |
| $Y$ | one-hot метки | $N\times K$ |
| $L$ | функция потерь | скаляр |
| $\eta$ | learning rate | скаляр |
| $\lambda$ | сила L2-регуляризации | скаляр |

## Главный принцип ручной реализации

Для каждого блока нужно уметь ответить на четыре вопроса:

1. Что он вычисляет в `forward`?
2. Какие промежуточные значения надо сохранить?
3. Какой локальный градиент используется в `backward`?
4. Какие формы имеют входы, выходы и градиенты?
